# Agro-Food CO2 Emissions and Sustainability

Data mining project for analyzing and forecasting agro-food CO2-equivalent emissions.

## Included files
- `app.py` — Flask dashboard application
- `dmpro.py` — data preprocessing, modeling, evaluation, feature importance, and forecasting pipeline
- `DM_final_report.pdf` — project report

## Notes
The analytics pipeline expects an agro-food emissions CSV containing fields such as `Area`, `Year`, and `total_emission`. Dataset files and generated result files are intentionally excluded from Git by `.gitignore`.
